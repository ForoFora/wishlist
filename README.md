# Вишлист Миши

Сайт для первого дня рождения. Карточки лежат в этом репозитории и открываются через GitHub Pages. Кто какой подарок забронировал, хранится отдельно, поэтому гость занимает подарок сам, и это сразу видно остальным.

[npoint.io](https://www.npoint.io/) для этого не подходит: с сайта можно только читать JSON, а записать бронь гость не может. Список поэтому лежит в общем ключе `storeKey` в `js/config.js`. Регистрироваться нигде не нужно.

## Как это работает

Гость нажимает «Забронировать», пишет имя, и подарок становится занятым у всех, у кого открыт вишлист. Снять бронь может тот же человек в том же браузере: кнопка «Снять бронь» освобождает подарок для всех.

Если кто-то ошибся и уже закрыл страницу, откройте `admin.html`, сотрите имя и нажмите «Сохранить».

Ключ списка есть в коде сайта. Для семейного вишлиста этого достаточно. Человек, который откроет исходный код, теоретически сможет изменить брони.

## Фото Миши

Положите снимки в папку `photos` и раскомментируйте строки в `js/config.js`:

```js
photos: [
  { src: "photos/misha-1.jpg", alt: "Миша" },
],
```

Короткий текст о ребёнке лежит в `index.html`.

## GitHub Pages

1. Создайте репозиторий на GitHub и залейте туда все файлы этой папки.
2. Откройте **Settings → Pages**.
3. Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
4. Сайт появится по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

Страница, где можно снять чужую бронь: тот же адрес с `admin.html` в конце.
